# screenshots/

**Status: empty, and deliberately so.**

There are no screenshots because nothing has been deployed. There are no dashboards, no alerts and no results to capture. Adding illustrative or placeholder images would misrepresent the state of this project.

Screenshots will be added when there is something real to show.

## Rules for images added here

Every screenshot must be sanitised before committing. Check for:

- [ ] AWS account IDs
- [ ] Real public IP addresses (use RFC1918 or TEST-NET ranges in any annotation)
- [ ] Hostnames and ARNs
- [ ] API keys, tokens or session identifiers visible in a URL or console
- [ ] Browser tabs, bookmarks, profile names or notifications revealing anything unrelated
- [ ] Email addresses and usernames

Crop tightly. Redact with a solid block — **never a blur**, which is sometimes reversible.

**No fabricated screenshots.** No mock dashboards presented as real, no edited alert counts, no composed images implying activity that did not occur.

## Naming

`<scenario>-<what-it-shows>-<YYYY-MM-DD>.png`

Example: `brute-force-alert-detail-2026-10-01.png`

Each image is referenced from the document it evidences, with a caption stating what it shows and when it was captured.
