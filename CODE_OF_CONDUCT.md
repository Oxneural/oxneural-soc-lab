# Code of Conduct

This repository follows the OxNeural organization code of conduct.

See [`.github/CODE_OF_CONDUCT.md`](https://github.com/Oxneural/.github/blob/main/CODE_OF_CONDUCT.md) once the organization profile is published, and the [OxNeural Handbook](https://github.com/Oxneural/oxneural-handbook) for engineering standards.

## In short

Professional conduct, respect in disagreement, honesty about what you know and do not know, and confidentiality where it applies.

Specific to this repository: **do not post real security findings, real log data, real hostnames, real IP addresses or credentials** in issues, pull requests or discussions. This is a lab. Everything published here is synthetic or belongs to the lab environment.
